Scripts
-------

Helper scripts used by the repository. Common scripts:
- `generate_changelog.py` — create changelog entries from git history
- `scan_secrets.py` / `run_security_checks.*` — security scanning helpers
- `test-frontend.ps1` — convenience script for frontend tests on Windows

Run Python scripts with `python scripts/<script>.py` or use the PowerShell helpers for Windows.
