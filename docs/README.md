Docs
----

This directory holds design documents, architecture notes, decisions, and operational guides.

Key sections:
- `architecture/` — architectural diagrams and system-level docs
- `design/` — component and design-spec docs
- `operations/` — runbooks and operational playbooks
- `decisions/` — ADR-style decisions and rationale

Read the top-level `PROJECT_SUMMARY.md` for a high-level overview and then follow links to component docs.
